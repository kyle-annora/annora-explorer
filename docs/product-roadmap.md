# Product opportunities after interface clarity

Recorded November 1, 2026. These are future proposals, not shipped capabilities.
The current milestone is limited to the existing Explorer's navigation, customer
information and control states. The public template remains a static application.

## Product Room

Connect three approved buyer questions to relevant views, product documents and
one next action. A future **Ask about this part** flow should carry the product,
exact model revision, selected part and saved view into a question or inquiry.
An optional project review host can later add an owner, response, decision and
quotation feedback. This continues the product-understanding-to-sales journey.

Use the existing JSON controller. `captureView` supports settled exploration and
paused manual operation, not arbitrary running-tour poses. Bookmarks require an
exact model revision; never silently remap comments to a different geometry export.
Durable sharing, accounts and customer data belong to the host's future backend,
not the public Explorer template. No backend or simulated persistence is included
in this milestone.

## Annora Studio

Start with repeatable delivery work: model readiness, approved names and facts,
materials, short-story authoring, device evaluation and release review.

A Story Composer can select a component and camera, bind an approved 2–3 second
action, supply a short explanation and preview its held endpoint. Its output
should be the existing model/tour package, not a second animation runtime.
AI assistance may propose copy or views grounded in supplied material; engineering
relationships and motion require review. Measure preparation effort on another
customer product before deciding which authoring tasks to automate.

## Evidence and order

1. Complete interface clarity with the approved floating visual style.
2. Validate a single Product Room and contextual inquiry with a real product.
3. Build a narrow Studio around the repeated preparation tasks.
4. Add durable review, integrations and sales insight only when real workflows
   and the Annora backend are available.
