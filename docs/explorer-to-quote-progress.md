## Stage 3 implementation boundary

An asset-free build of the shared inquiry can exclude models, Three.js, PDF and
Studio UI. MK already owns a draft/review/confirmation repository; an adapter
must retain it rather than create a parallel commercial store. The full MK brief
and open questions must be reviewed before its existing confirmation token is
used. A new hook may be needed for that adapter-owned review boundary.

The existing MK viewer exposes camera bookmarks, but not the shared inspection
or orbital capture contract. Start a bounded proof through an explicit supported
Explore transition and disclose that the preceding orbital pose is not captured.
Preserve its existing ordinary projects and publish only from an isolated client
candidate after refreshing its registered sources and release record. A shared
bundle build alone does not complete the customer reuse milestone.
