# Independent viewer example

Mode: Experience, with an Operate inquiry sheet. This extends the existing Annora visual system; it does not replace Explorer or add a new brand.

The public crank occupies the primary canvas. A compact left introduction explains why the request keeps a view; the lower selection panel offers a keyboard alternative to raycasting. The top contains saved inquiries and one primary quote action. The reviewed inquiry is the existing shared floating surface.

Reference lock: the approved Annora workspace and embedded inquiry are authoritative. Refero Linear reference `554b801c-3b31-4086-a7e5-ae613cdd618b` supports compact control grouping only; its dark palette and lime are deliberately not adopted. Faire's [Request Unlisted Product flow](https://refero.design/flows/13083) supports requesting within the browsing context; this example retains Annora's separate review and confirmation instead of copying immediate submission.

Host-local values stay consistent with Annora's neutral and Ember palette: canvas #f3f3f1; surface #ffffff; ink #282b2d; secondary #65696d; borders #d7d8d7; Ember #ff6840 for model selection; 44 px controls; 5–6 px host control/surface corners, 4 px selectors and the shared inquiry's 8 px mobile corners. The host uses Arial/Helvetica, while the unchanged shared workspace prefers Helvetica Neue. Controls are 12–14 px, mobile select text is 16 px to prevent input zoom, and the compact heading is 30 px/25 px. No new display type, background illustration or promotional card system.

Mobile keeps the model above the selection controls. The request remains a resumable floating panel, with an explicit Keep exploring action. Every hover action has a touch and keyboard equivalent. Long IDs remain inside expandable version details.

Unavailable drawings/story capabilities are explained in About this integration, not represented as working tabs. Loading blocks dependent actions. Save/read failures keep the current editor and show an actionable error. Fake data and browser-local persistence are labelled.
