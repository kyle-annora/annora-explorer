# Connecting rod: paired CAD and drawing reference

This package adds a linked drawing reference without changing the existing Apollo or crank projects. The model is **one actual CAD solid**, not an invented assembly. Large bore, small bore and connecting web are detail regions of that same body.

## Source and version

- CAD: [Open CASCADE Technology `data/step/linkrods.step`](https://github.com/Open-Cascade-SAS/OCCT/blob/7fd59977dfb3a75f75670474b59dfc0f3f5f90ba/data/step/linkrods.step), last changed at `7fd59977dfb3a75f75670474b59dfc0f3f5f90ba`. Verified byte-identical against current OCCT as recorded in `provenance.json`.
- Published paired STEP and PDF: [pzfreo/dw-examples snapshot `c4c72a71`](https://github.com/pzfreo/dw-examples/tree/c4c72a71c6440f0c824678660b59d0474f105e71), generated by draftwright v0.2.5. The upstream README identifies this PDF as output of the same STEP and `source-drawing-spec.json`.
- `linkrods.step` and `sheet.pdf` are redistributed **unchanged**. `sheet.svg` is a vector conversion of that PDF, with no added dimensions or annotations.
- License: GNU LGPL 2.1 with the Open CASCADE exception. Copyright Open CASCADE SAS. See `LICENSE.txt` and `source-occt-notice.md`. Source STEP, drawing specification, transformation scripts and source review accompany the derived preview.

The display identifier `source-c4c72a71` is a **repository snapshot**, not a manufacturer-issued drawing revision. The source title block does not supply a revision, material, general tolerance or approval.

## Drawing status

The source is an **unreviewed reference drawing**. It is useful for testing linked selection, detail requests and immutable source references; it is not a fabrication release. Keep this status visible in the preview and carry it into an inquiry.

The source review records 18 freeform surfaces not fully dimensioned, a missing general tolerance, one extension line crossing a hole, rounded printed nominal dimensions and 11 faces unclaimed by recognition. The original `source-review.json` is retained. No tolerances, materials or approval are inferred here.

The model uses millimeters in STEP. Its small nominal dimensions are those of the original OCCT sample; this package does not rescale it into a plausible production-size rod. Printed bore dimensions are rounded by the source drawing. The STEP cylinders support approximately 1.034469 mm and 0.439847 mm bores; the drawing prints 1.034 and 0.440 mm. Horizontal bore spacing is 3.875 mm with a 0.125 mm offset.

## Linked selection contract

`drawing.json` provides the immutable PDF hash, source snapshot, sheet dimensions and four region records. Region bounds are `[x, y, width, height]` in the SVG/PDF viewBox. `pdfPage` is one-based. All regions resolve to the real Explorer part ID `linkrod-body`; the navigation group is `link-body`.

Detail focus points are in the derived GLB frame: `[x, y, z]` in meters, Y up. The CAD-to-preview conversion is `[x, y, z] mm -> [x, z, -y] / 1000 m`. Focus points identify features for framing only. They are not assembly pivots or measurement results.

Persist drawing ID, source snapshot, original PDF SHA-256, sheet ID, region ID and part ID with a selected inquiry detail. Do not silently replace the source revision when resolving a saved inquiry later.

## Preparation and reproducibility

The runtime downloads a prepared GLB; STEP parsing runs only during asset preparation. No CAD kernel is added to the browser.

Pinned preparation settings: occt-import-js 0.0.23; 0.006 mm linear deflection; 0.2 rad angular deflection. Output is one mesh, 15,242 triangles and 9,252 vertices. The compressed GLB is about 197 KB; prepared contour data is about 136 KB compressed. Engineering finishes are illustrative.

From the repository root, install the CAD converter outside the application dependencies and prepare a temporary GLB:

```sh
npm install --prefix /tmp/annora-linkrods-tools occt-import-js@0.0.23 --no-audit --no-fund
node content/drawings/linkrods/source-tools/tessellate-step.cjs /tmp/annora-linkrods-tools/node_modules/occt-import-js content/drawings/linkrods/linkrods.step /tmp/linkrods-mesh.json
python3 content/drawings/linkrods/source-tools/make-preview-glb.py /tmp/linkrods-mesh.json /tmp/linkrods.glb
npm run import:model -- --source /tmp/linkrods.glb --definition content/drawings/linkrods/model-definition.json --out /tmp/linkrods-prepared
```

The Python conversion helper requires NumPy. Preparation uses no external textures, compression extensions or generated motion. The importer intentionally refuses to overwrite an existing model package.

To recreate the SVG, use Poppler's `pdftocairo -svg sheet.pdf sheet.svg`. The original PDF is the authoritative published drawing artifact; SVG byte hashes may change across Poppler versions. Verify source identity and prepared assets with:

```sh
node content/drawings/linkrods/source-tools/verify-source.mjs
```
